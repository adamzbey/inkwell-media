Make a QR code

Type a link, some text, Wi-Fi details, an email address or a phone number and the QR code appears as you type. Choose the colours, add a logo in the middle and download a PNG or a sharp SVG for print. These codes hold the information directly, so they never expire and don’t depend on any website.

Ideas

  • Wi-Fi for guests so nobody has to type the password.
  • Flyers and menus that open your website.
  • Business cards that start an email or a call.
  • Event signs that link to tickets or a form.

Static or editable?

These codes are static: what you type is inside the code itself, so they work forever with no account. The downside is you can’t change where a printed code points. If you need that, or want to count scans, use an editable code from Inkwell Blot.

Frequently asked questions

Do these QR codes expire?

No. The link or text is stored in the code itself, so it keeps working as long as the link does.

Is anything I type sent anywhere?

No. The code is made in your browser. Your Wi-Fi password and other details never leave your device.

Can I add my logo?

Yes. The code uses extra error correction when there’s a logo, so it still scans. Always test it with your phone before printing.

Which file type should I use for print?

SVG. It stays sharp at any size. Use PNG for screens, documents and social posts.
